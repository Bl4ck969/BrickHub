Erstes Release über den Kanban-Leitstand: BrickHub bekommt eine Versionsnummer (2.0.0, passend zum Design 2.0, das seit 12.09.2026 läuft) – an der App selbst ändert sich nichts.

## Neu
- **Versionsnummer 2.0.0.** Ab jetzt hat jede veröffentlichte Fassung ein Tag `vX.Y.Z` auf GitHub. Die Weboberfläche zeigt die Version nicht an; Oberfläche, Daten und Bedienung bleiben genau wie bisher.
- **Prüfung vor dem Release.** Vor jedem Release kann jetzt eine Probe-Instanz auf dem PC mit der letzten automatischen Sicherung gebaut werden, um Neues dort statt am Unraid auszuprobieren. Das betrifft nur den Ablauf hinter den Kulissen.
- **Automatischer Bautest.** Jeder Änderungsvorschlag (PR) baut das Docker-Image einmal zur Probe, ohne es zu veröffentlichen.

## Für den Betrieb
- Nichts zu tun, nur das Update am Unraid. Keine neue Umgebungsvariable, kein neuer Mount, kein Portwechsel.
