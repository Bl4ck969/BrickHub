Diese Fassung macht BrickHub robuster: verständliche Fehlermeldungen statt weißer Seiten, eine sichere Sicherung/Wiederherstellung und strengere Prüfung hochgeladener Bilder. Neue Funktionen gibt es nicht.

## Behoben
- **Keine weiße Seite mehr bei Fehlern.** Ging beim Speichern etwas schief (zum Beispiel eine ungültige Eingabe), konnte die ganze Seite weiß werden. Jetzt erscheint eine verständliche Meldung auf Deutsch, und stürzt eine Seite doch einmal ab, zeigt BrickHub einen Hinweis statt einer leeren Fläche – die Seitenleiste bleibt bedienbar.
- **Hängende Anfragen brechen ab.** Antwortet der Server gar nicht mehr, meldet die Oberfläche nach spätestens 5 Minuten eine Zeitüberschreitung, statt endlos zu warten. Das Hochladen einer großen Sicherung ist davon ausgenommen.
- **Sicherung und Wiederherstellung laufen nicht mehr doppelt.** Auf der Seite „Backup“ kann immer nur ein Export oder ein Import gleichzeitig laufen; ein zweiter Start bekommt die Meldung „Es läuft bereits ein Import oder Export“. Vorher konnte ein Export von Hand während einer Wiederherstellung einen halb ersetzten Datenbestand sichern.
- **Lange Sicherungen verlieren den Fortschritt nicht mehr.** Dauert ein Export länger als 10 Minuten oder ein Import länger als 20 Minuten, verbindet sich die Fortschrittsanzeige von selbst neu, statt ohne Ergebnis hängen zu bleiben. Abgeschlossene Sicherungsaufträge, die älter als eine Stunde sind, werden beim nächsten Export oder Import aufgeräumt – samt nicht abgeholter Export-Datei.
- **Nur echte Bilder werden angenommen.** Beim Hochladen eines Covers prüft BrickHub jetzt den Inhalt der Datei (JPEG, PNG oder WebP) und lehnt übergroße Bilder (über 80 Megapixel) ab. Vorher zählte nur, was der Browser über die Datei angab.
- **Gelöschte Sets hinterlassen keine Bilder mehr.** Beim Löschen eines Sets werden seine Cover-Bilder mit entfernt, außer ein anderes Set nutzt dieselbe Datei. Neue Bilddateien tragen die interne Nummer des Sets im Namen, damit gleichnamige Sets sich keine Dateien mehr teilen.

## Bekannte Einschränkungen
- Die automatische Sicherung und der Knopf „Jetzt sichern“ achten noch nicht auf eine laufende Wiederherstellung. Am besten während einer Wiederherstellung keine Sicherung von Hand starten.
- Bilder, die vor diesem Update beim Ersetzen eines Covers liegen geblieben sind, bleiben liegen; aufgeräumt wird nur beim Löschen eines Sets.

## Für den Betrieb
- Nichts zu tun, nur das Update am Unraid. Keine neue Umgebungsvariable, kein neuer Mount, kein Portwechsel.
