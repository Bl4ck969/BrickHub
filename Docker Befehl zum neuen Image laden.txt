Docker Befehl zum neuen Image laden:

docker stop Brickhub && docker rm Brickhub && docker pull ghcr.io/bl4ck969/brickhub:latest


Docker Befehl zum neuen Container bauen:

docker run -d \
  --name='Brickhub' \
  --net='bridge' \
  --pids-limit 2048 \
  -e TZ="Europe/Berlin" \
  -e HOST_OS="Unraid" \
  -e HOST_HOSTNAME="Unraid-Server" \
  -e HOST_CONTAINERNAME="Brickhub" \
  -l net.unraid.docker.managed=dockerman \
  -l net.unraid.docker.webui='http://[IP]:[PORT:8049]/' \
  -p 8049:8080/tcp \
  -v '/mnt/user/appdata/brickhub/data':'/app/data':'rw' \
  -v '/mnt/user/appdata/brickhub/export':'/app/export':'rw' \
  -v '/mnt/disk2/Backups/BrickHub':'/app/backup':'rw' \
  --restart unless-stopped \
  ghcr.io/bl4ck969/brickhub:latest

Hinweis: SECRET_KEY wird automatisch aus /mnt/user/appdata/brickhub/data/.env
gelesen (persistentes Volume). Kein --env-file oder -e SECRET_KEY nötig.


Einmalige Einrichtung der .env-Datei (nur beim ersten Mal):

# Neuen sicheren Key generieren:
openssl rand -hex 32

# Key in .env speichern (generierten Key einsetzen):
echo "SECRET_KEY=HIER_GENERIERTEN_KEY_EINSETZEN" > /mnt/user/appdata/brickhub/data/.env
